# Changelog

## 0.1.1 - Unreleased

- `cls --shots` now captures a screenshot at each shift, with the moved elements outlined.
- Added `cls --out` (default `./wpsk-cls`).
- With `--device both`, `--runs` counts per device.
- `--cta` links the report footer when an `https://` URL follows the bar.
- Added the usage guide (`docs/usage.md`) and a README example.

## 0.1.0 - 2026-10-23

- Added `wpsk audit` for repeatable local Lighthouse lab reports.
- Added `wpsk cls` for layout-shift recording and evidence.
- Added `wpsk compare` for before/after report comparisons.
